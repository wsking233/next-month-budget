# 领域层

`budget.ts` 是与 React、Zustand、UI 和存储无关的纯 TypeScript 内存账本。金额使用安全整数分，累计与分配核对使用 BigInt 保持精度；函数校验后返回新账本，错误不修改输入。

支持周期、资金池、拨款、账单资料、跨期拆分、结算、调拨、更正与撤销。余额通过原始流水及追加冲销按周期累计计算；审计保留当时资料描述和原因。资金池停用、去重、资料修改和重结算约束见 docs/03、04。

领域测试覆盖负结转、未来隔离、守恒、失败原子性、去重、多次更正撤销、停用、重新结算、日期及精度边界。业务 UI 已接入此模型；Phase 4 已通过独立 `src/storage/` 实现校验及本地保存，领域本身不读写存储。退款、分期、部分还款等未决规则未实现。

`income.ts` 实现固定模板、收入分配及追加冲销撤销；`analytics.ts` 的拨款口径包含收入冲销净额。计划储蓄是目标，收入关联拨款与独立手工拨款分别展示。存储 v2 包含可选 planning，并支持 v1 严格校验后的迁移。

`credit.ts` 管理本地信用卡账户、旧账单显式关联及实际还款/撤销；这些操作均不生成预算流水，预算结算和还款状态独立。存储 v3 验证账户引用、还款总额、防重及审计完整性，支持旧格式读取。
