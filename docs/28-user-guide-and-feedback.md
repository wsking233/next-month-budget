# 使用说明与实际体验反馈

适用：v0.11.0。当前是浏览器本地应用，无登录、银行连接或跨设备同步。

## 第一次使用

1. 可先打开「查看独立演示」熟悉操作；演示不保存到用户账本。正式使用前返回本地账本。
2. 在概览按建账进度创建预算周期与资金池。周期可从发薪日开始，日期手工填写；正负预算自动通过流水结转，不会月末清零。
3. 在预算计划编辑固定金额模板，再登记实际收入，核对拨款、计划储蓄及未分配额后确认。收入不足必须调整；已有手工拨款不会自动抵扣，注意不要重复安排。
4. 在设置创建信用卡账户；旧账单可在账单卡片中逐张预览并确认关联，原名称保留，不自动合并。
5. 登记账单金额、标识、账单日与还款日，按池与预算周期拆分。合计匹配后核对并确认，才扣预算。
6. 实际还款另行登记，可分次；标识在单张账单内唯一，日期手工填写，累计不超账单。填充未还金额只改输入，仍须确认。已结算不代表已还款，已还清也不代表已分配预算。
7. 在设置导出 JSON，再确认浏览器确实保存了文件。文件未加密，应妥善保管。

预算余额不等于银行现金；计划储蓄不是已实现存款。到期列表仅依据填写的日期和有效还款记录，不能证明银行已到账，也没有系统推送。

## 快速找记录

- 账单可组合筛选预算结算状态、实际还款状态、稳定信用卡账户、旧账户文字及到期区间；可按登记或到期顺序排序，清空筛选后还原。停用或改名的账户仍保留关联。
- 收入可按周期、状态及标识检索；列表可跨周期查询，上方汇总仍是当前查看周期的有效收入。
- 历史记录按操作顺序保留原资料与原因；筛选和搜索不改账务。

## 录错如何处理

- 账单只改分类或归属周期：更正分配并写原因。
- 账单总额或日期等资料有误：已结算的先撤销结算，再修改资料、重新结算。总额不能低于有效已还金额。
- 还款录错：撤销还款记录并写原因，再用新标识登记。撤销不代表银行退款，也不改变预算。
- 收入录错：撤销收入及关联拨款，再以新标识登记；原消费保留，未来预算可能变负。
- 跨池补预算：使用有明确来源、去向与原因的调拨，不直接改余额。

## 备份、升级与恢复

- 备份提示保存的是文件生成时间、账本摘要与开关，不能确认下载或保管。切换查看周期和演示不算账务变更；提示可关闭，摘要不可用仍可导出。
- 当前格式为3，可严格读取旧格式1/2；读取本身不覆盖本地，后续成功保存才升级。新备份不能用于旧版应用。
- 恢复前先导出当前账本；选择备份并核对源版本、记录数量与覆盖范围，确认后整体替换，不合并。取消、校验失败或存储失败保留原数据。
- 读取损坏时不要反复清空，先下载原始存储留存，再尝试有效备份恢复。空间或权限错误时，本次操作不生效，保留输入供处理后重试。
- 同时打开多页时，支持独占编辑保护的浏览器只允许一页编辑。关闭原编辑页，等待页会自动读取最新账本后接力；等待期间可查看、导出或使用演示。锁请求失败时请先导出备份，再刷新重试。旧版页面和不支持保护的浏览器需只开一页；不会自动合并修改。
- 恢复预览后若账本变化，请取消并重新选择文件核对。清理站点数据或设备丢失可能丢账本，独立导出文件是必要保护。

## 实际设备验收清单

建议先用无敏感数据走完一轮，结果按设备分别记录；自动化移动视口不能替代实际手机。

- 日期选择与金额小数输入是否顺手，软键盘是否遮住确认按钮。
- 弹窗能否滚动到末尾，取消与错误后是否能继续修正。
- 建账、收入分配、跨期拆分、分次还款与撤销是否可完成。
- 刷新/关闭重开是否恢复，JSON是否确实可找到并选回；恢复预览、取消及确认是否符合预期。
- 长账户名称、长标识、浅深色及窄屏是否可读、可操作。

当前尚未记录实际手机硬件验收结果，不能据此宣称已通过真机认证。
