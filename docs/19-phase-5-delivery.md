# Phase 5 统计与预算规划

版本：0.5.0。来源为当前工作区同一领域账本；不读取外部数据，不改变备份格式。

## 交付

概览新增本期收支桥梁、按资金池筛选的结转趋势、最近六个真实周期的精确明细、拨款分布。负数保留，拨款分布的分母仅为当期拨款，不把净余额当成资产比例。已停用资金池仍保留在历史统计中，更正和撤销后的净流水自动反映到统计。

预算计划新增只读模拟：从所选周期余额起算，用户逐池输入每期额外拨款与预算结算，默认为零。可选择叠加已有未来周期流水；超过真实周期后以模拟序号标记，不自动推定日期。未分配账单不纳入，不推断收入或储蓄；生成、修改、重置或离开模拟都不写入真实账本及 localStorage。

走势图为轻量 SVG，提供零线、原生点提示与完整精确金额明细；比例和图形坐标仅用于展示，计算使用整数分与 BigInt 中间汇总。无周期/资金池时展示空状态，零拨款没有假比例。

## 手动验收

1. 建立周期、资金池、拨款和结算，检查“结转 + 拨款 − 预算结算 + 净调拨 = 期末余额”。
2. 查看独立演示，结算 A 卡到数码池，使余额为负。切换趋势资金池与查看周期，检查明细和零线下的负余额。
3. 更正原账单归属周期，再撤销，检查各期结算额与后续结转同步更新。
4. 预算计划中输入每期额外拨款，生成模拟，检查负数先被抵扣；勾选/取消已有未来流水，重新生成。
5. 修改假设后旧结果隐藏，重新生成才显示；刷新后假设消失，本地账本与审计不变。
6. 375 / 768 / 1440px 检查图表、明细、输入、空状态与深浅主题。

模拟口径属于用户显式假设，不保证未来现金、可还款金额或实际储蓄。用户授权继续自主开发，发布本阶段后进入 Phase 6。
