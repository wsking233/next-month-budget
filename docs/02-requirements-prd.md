# 产品需求文档 PRD｜初稿

状态：Draft（待实际账单验证）。

## 核心使用流程
1. 初始化：设置发薪周期、默认收入、目标储蓄、消费拨款及资金池。
2. 发薪：确认实际收入，生成当期资金池拨款和计划储蓄。
3. 出账：选择信用卡、输入账单金额、日期和对应还款日。
4. 分类：将账单总金额拆分给多个资金池，必要时指定不同预算周期。
5. 确认：校验拆分合计与总额一致，生成可追溯预算流水。
6. 复盘：显示资金池可用余额、负余额、未来拨款抵扣、预算目标与还款日程。

## P0（首版必须）
- 自定义预算周期起始日，支持非自然月。
- 资金池创建、编辑、停用；设置每期拨款金额。
- 正负余额跨期滚存，不自动归零。
- 账单登记与分类拆分；多信用卡不同账单日/还款日。
- 用户可调整预算归属周期；默认规则见结算文档。
- 严格校验：分配金额合计必须等于账单金额。
- 手工预算调拨、明确来源/去向、保留操作记录。
- 账单编辑、更正、撤销与防重复结算。
- 区分预算可用余额和真实现金/信用卡负债。
- 本地保存、手动备份和恢复；无网络可用。
- 至少包含首页、资金池、账单结算、未来预算、历史记录。

## P1（验证后）
- 按工资周期的未来预算预测与年度储蓄计划。
- 待还账单提醒、本地通知。
- 批量结算、结算模板和上期快速复用。
- 月度复盘及超支原因记录。

## 不做（首版）
- 银行 API 自动同步、逐笔自动抓取、投资理财。
- 多人账户、Parent Control、商业化收费。
- AI 账单识别、复杂多级类别、云端账户系统。
- 为 Web 单独维护另一套独立产品。

## 核心界面
- 首页：本期计划收入/储蓄、资金池汇总、待处理账单。
- 资金池：余额、每期拨款、累计历史及调拨操作。
- 结算：账单总额、分配明细、未分配差额、归属周期。
- 计划：未来各期预算余额、负数预计何时归零。
- 记录：账单、拨款、更正、调拨的审计时间线。

## 验收场景
1. 数码资金池余额 2,000，扣 4,000 后成为 -2,000；下期拨 2,000 后为 0。
2. 两卡账单跨不同还款周期，分别计算预算归属，无双重扣除。
3. 单张 6,200 账单分配 2,800 + 2,100 + 900 + 400，全额匹配。
4. 调拨 1,000 时两边同步变动，预算总额不变。
5. 同一张已确认账单再次导入或保存，不能形成重复扣减。
6. 更正历史结算后未来资金池余额可重算且可追溯。
