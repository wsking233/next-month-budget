# v0.9 信用卡账户与实际还款

日期：2026-10-18。用户确认的五项还款规则已实现。

设置提供本地信用卡账户创建、改名、停用。新账单可选择稳定账户，旧账单逐张预览确认关联，保留原账户文字，不按名称自动合并。关联与财务审计独立，防止同账户内重复账单；停用不删除历史或阻止历史还款。

账单可登记分次实际还款、展示已还及未还、撤销错误还款并保留原因。单张账单内还款标识防重（撤销后仍保留），累计有效还款不超过账单总额。修改账单金额不可低于有效已还额；已关联账户不改换，改名在账户管理进行。还款日期、账单日期与还款到期日手工填写，不自动推算。

还款与预算结算独立：不生成预算流水，不自动改变结算状态，不标记银行已核对；撤销预算结算不撤销还款。到期列表基于手工记录，覆盖所有预算周期，已还清排除，已撤销预算结算仍可能待还。仅页面内提示，不接入银行、通知、退款、分期、利息或超额还款。

快照 v3 包含可选 credit 和 Statement.creditAccountId；v1 / v2 先按原严格 schema 校验，再无损内存转换。读取不改写本地；成功保存才升级，失败保留旧文件。新备份不兼容旧应用，仍限制2MB。

验收覆盖还款/结算顺序等价、部分/全额、超额与防重、撤销、资料修正约束、停用与改名、旧账单关联、损坏审计拒绝、旧格式迁移及存储失败重试。最终结果：`npm run check` 通过（77 项单元/界面测试、lint、类型及生产构建）；三浏览器全量 93 项通过，再补充新账单选择账户、改名、停用及资料修正场景，三引擎各1项通过，当前96项均有通过证据，无跳过。连续三周期综合验收通过，见 `docs/25-release-candidate-validation.md`。
