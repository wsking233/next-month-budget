1. 完成 iPhone 真机冒烟验收：原生底栏、六个标签页、系统返回手势、深浅色、动态字体与冷启动。
2. [x] 用脱敏样例冻结首批领域测试：负余额跨期、跨期归属、调拨原子性、取消/更正和防重复结算。
3. [x] 建立纯 TypeScript 领域模型与测试，不接数据库；所有金额以最小货币单位整数表示。
4. [x] 实现内存演示最短闭环：建立预算周期 → 创建资金池 → 拨款 → 登记并结算账单 → 查看余额与审计记录。
5. 最短闭环稳定后再接入 Expo SQLite、事务、Schema 版本和本地备份，不提前引入服务端。
