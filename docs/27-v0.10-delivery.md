# v0.10 日常操作效率交付

日期：2026-10-18。对应 `docs/26-post-v0.9-development-plan.md` 第一阶段。

- 账单支持实际还款状态、预算结算状态、稳定信用卡账户、原账户文本、到期日组合筛选及登记/到期顺序排序。稳定账户ID不受名称修改影响，停用账户仍可查询；未关联旧账单单列筛选。重置还原全部条件，筛选不写入账务。
- 历史收入可按周期、应用/撤销状态及标识搜索；列表显示归属周期和分配金额，筛选不改变上方所选周期的有效收入汇总。
- 模板当前金额合计与所需收入可预览，复制显示来源周期及净拨款口径，停用池排除仍明确提示。收入确认按最新账本验证；预览后账本变化时须重新预览。
- 还款按钮可将当前未还整数分精确填入元输入，不自动填写日期、生成标识或提交。确认继续走领域防重、超额及先保存再应用保护。
- 独立备份偏好保存生成时间、账本规范化内容SHA-256摘要及提醒开关。比较不含主题、查看周期或导出时间，不保存另一份完整财务数据。演示不改变用户状态；提示可关闭；跨页/刷新保留，偏好失败只保留本页提示。
- 文件生成不等于下载完成。摘要不可用时明确无法比较，不阻断导出或账本操作。恢复预览显示源格式与当前格式版本，以及预算流水、收入、还款和审计数量，仍为整体覆盖、二次确认。

账本格式仍为3，v1/v2严格读取及失败保全继续有效；没有新收入/还款策略、后台、银行、PWA、退款或预占规则。

新增测试覆盖组合筛选、稳定ID边界、排序无写入、收入检索、模板来源与合计、未还填充、备份后变更、切周期与演示隔离、偏好失败、摘要不可用及旧备份取消恢复。实际结果：`npm run check` 通过（79 项单元/界面测试、lint、类型及生产构建）。三浏览器全量中105项直接通过，9项恢复场景因旧文案断言失败；同步“预算流水”文案后，三浏览器九项完整恢复流程全部复跑通过。当前114项浏览器检查均有通过结果，无跳过，应用代码在该断言修正期间未改变。

正式 v1.0 仍待实际设备/浏览器体验反馈，见候选验收文档；预占与退款等新规则继续单独确定。
