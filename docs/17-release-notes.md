# 版本交付记录

## v0.2.0 — 交互原型
- 六页面改为表单、卡片、账单拆分、差额核对和空状态。
- 显式演示空间，默认零数据；原型确认只反馈、不真实入账。
- 校验：ESLint、TypeScript、13 项单元/路由测试、生产构建通过。
- 浏览器自动化待补齐：运行环境没有浏览器，下载 CDN 返回策略拒绝；后续阶段解决。
- 手验：进入演示 → 账单 → 分配 → 添加一行 → 差额不为零时不能确认；切换六页面及深浅主题。

## v0.3.0 — 账务闭环
- 从零创建周期/资金池、拨款、账单登记/分配、调拨、更正、撤销及重新打开。
- 编辑资金池、未结算账单；常规拨款仅作预测配置；还款独立登记、不扣二次预算。
- 日期严格校验、去重标识规范化、名称防重、整数分边界；追加审计时间及编辑前后信息。
- 验证：18 项测试、lint、类型、构建通过；系统 Chromium 上 375/768/1440px 六路由/深浅色/无溢出检查全部通过。
- 手验：创建两期和两池 → 首期拨款 2000 → 结算 4000 → 余额 -2000 → 下期拨款 2000 → 余额 0；调拨、重复结算、更正撤销后检查历史。
- 限制：本阶段仅内存；刷新丢失提示持续显示。还款流水不支持更正；银行退款、分期、跨币种未实现。

## v0.4.0 — 本地账本与备份恢复
- 独立 LocalStorageRepository + Zustand：存储成功后才更新内存；配额失败、损坏快照保全旧数据。
- Schema v1 + 完整性校验、引用/配对/余额/审计/还款一致性验证；8MB 文件限制。校验码发现意外损坏，不提供加密或抗恶意篡改。
- JSON 下载、恢复预览及输入确认、清空确认、损坏原始文件下载；不上传数据。
- 支持 Web Locks 时单标签页独占写入，其他标签页只读、接力时重新载入；无此 API 的浏览器有明确单标签页提示并保留版本冲突检查。
- 新增还款错误登记作废，保留金额、日期及带原因的审计；不撤销银行支付。
- 验证：30 项单元/集成测试、lint/类型/构建及 9 项 Chromium 浏览器验收通过。完整业务、负数结转、更正还款、刷新、备份清空恢复在 375/768/1440px 跑通；配额/损坏/演示隔离/多标签页保护通过。
- 修复浏览器验收发现的表单标签问题：label 与控件使用唯一 ID 关联，提示通过 aria-describedby 连接。
- 手验：创建账本并刷新 → 导出 → 清空（需确认）→ 选择备份 → 核对预览 → 输入确认恢复；错误文件不能覆盖。
