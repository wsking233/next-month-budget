# 首版交互流程

状态：交互原型基线；业务规则仍以已确认文档为准。

## 导航结构（2026-10-16 简化）

- **概览**：底部常驻入口。只显示当前周期、可用预算、账单状态和“结算新账单”主操作。
- **账单**：底部常驻入口。查看已结算账单并快速开始下一次结算。
- **设置与管理**：从概览进入，集中放置预算周期、资金池、拨款、操作记录、备份和产品说明。
- **低频页面**：周期、资金池与审计记录不再占用底部导航，但保留完整能力。

列表型入口必须让整行可点击，并使用图标、数值、状态和右侧箭头表达层级；主要提交操作使用完整宽度的强调按钮。

## 主流程

1. **首次设置**：从概览进入“设置与管理”，依次建立周期、创建资金池并进行首次拨款。
2. **创建资金池**：输入名称并确认；创建资金池不等于拨款。
3. **预算拨款**：选择周期与资金池，输入金额；提交后生成独立预算流水。
4. **账单结算**：输入账户昵称、账单标识、总额和到期日，为一个或多个资金池填写分配金额。
5. **核对提交**：页面显示“已分配 / 账单总额 / 差额”；差额不为零时不能提交。登记与结算在一次领域状态转换中完成，避免只登记半张账单。
6. **结果确认**：返回账单页查看状态；日常只需回到概览查看余额，详细管理与记录按需从设置进入。

## 交互原则

- 创建、拨款、结算是三个独立动作，不自动连带执行。
- 不允许静默跨池调拨；后续调拨必须单独提供来源、去向、金额与原因。
- 金额输入以“元”展示，提交时严格转换为整数“分”。
- 表单错误留在当前页面显示；成功后才返回列表。
- 当前数据仅保存在内存，页面需持续标明“重启后重置”，避免误认为已持久化。
