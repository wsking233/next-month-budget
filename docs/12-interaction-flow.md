# 首版业务交互流程（平台无关）

状态：业务交互基线；后续 Web 响应式布局与导航需重新设计。

## 主要功能区域
- **概览**：当前预算周期、资金池余额、待结算账单及快速结算入口。
- **账单**：登记信用卡账单、拆分资金池、选择预算归属周期、核对差额、查看结算状态。
- **预算管理**：创建周期、管理资金池、执行拨款及显式调拨。
- **历史与维护**：审计记录、历史账单、更正/撤销、备份和恢复。

这些是业务功能分组，不规定侧边栏、顶部导航、底部标签栏或页面实现方式。

## 主流程
1. 首次设置：建立预算周期、创建资金池、配置预算拨款。
2. 创建资金池：输入名称并确认，创建行为不自动拨款。
3. 拨款：选择预算周期、资金池和金额；提交后记录独立流水。
4. 账单登记：填写账户、账单标识、总额及还款日。
5. 账单分配：填写一个或多个资金池、金额和预算归属周期。
6. 校验与确认：清晰展示已分配金额、账单总额和差额，差额不为零时禁止提交。
7. 查看结果：账单状态与预算余额更新，保留审计线索。

## 交互与数据原则
- 创建、拨款、结算为三个独立动作。
- 跨池调拨必须显式选择来源/目标、金额并输入原因。
- 金额以元显示，业务层以整数分处理。
- 输入错误不得丢失用户已填写的有效信息。
- 仅确认成功后才允许展示业务操作已完成。
- 未持久化的演示环境必须醒目标注数据不会保留；不得误导用户。
- Web 端移动和桌面布局均须支持完整主要业务流程。
