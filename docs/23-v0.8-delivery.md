# v0.8 固定预算与收入交付

日期：2026-10-18。用户确认固定金额模板、手动预览确认及不足额手动调整。

预算计划页提供模板编辑、复制所选周期净拨款、实际收入登记与预览、收入关联拨款及计划储蓄汇总。模板不自动应用，多个收入按周期内唯一标识防重；手工拨款独立，页面提示避免重复。收入日期及归属周期人工填写。

确认后整个操作先通过快照校验及存储，再发布状态。撤销保留原记录、追加拨款冲销及原因，不撤销消费，不代表实际退款。计划储蓄及未分配额均不是银行存款。

领域在 `src/domain/income.ts`，不读写存储或依赖 UI。快照版本 2 支持新记录，保留 v1 原严格 schema，先校验后转换；只读取不覆盖，首次成功保存才升级，失败保留旧文件。未知版本继续拒绝，新备份不能供旧应用读取。单文件上限继续 2 MB。

验证包含模板与历史隔离、固定分配守恒、不足额、防重、多笔收入、未来隔离、撤销负结转、整数边界、损坏恢复拒绝及 v1 迁移失败保全；浏览器覆盖真实预览确认、重复提交、写入失败重试及刷新恢复。最终结果：`npm run check` 通过（68 项单元/界面测试、类型、lint 与生产构建）；Chromium、Firefox、WebKit 全量 84 项检查通过，无跳过，包含六页深浅主题审计及新收入弹窗审计。

下一阶段还款范围仍待确认；不实现退款、分期、银行接入或 PWA。
