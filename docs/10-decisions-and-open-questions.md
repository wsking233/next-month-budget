# 决策记录与待确认问题

更新日期：2026-10-16

## 已定方向
- 名称：下月再说（Next Month，英文工作名）。
- 目标：个人预算管理，而非逐笔记账/金融投资软件。
- 先做自用产品，不把商业化和家庭共享列为首期目标。
- 资金池允许累积和负数结转；禁止自动无痕挪用。
- 多张信用卡以独立账单输入，但纳入统一预算体系。
- 把账单日、还款日、预算归属周期明确区分。
- 首版移动端iOS优先，React Native + Expo + TypeScript，本地优先。
- 本次 GitHub 初始化只有文档，不写任何业务代码。

## 临时建议，尚未正式确认
- 发薪日作预算周期起始日（示例为每月10日）。
- 账单默认归属还款日所在工资周期。
- 预算类别样例为日常/数码兴趣/不定期开支。
- 以每月20,000收入、13,000储蓄、7,000消费额度进行初始示例。
- 信用卡结算可跨预算周期拆分。
- 手动 JSON 备份恢复是首版必要能力。
