# 竞品观察

此文档为初步观察，非完整市场研究；细节应按实际产品版本验证。

## Goodbudget
- 信封预算方法与本项目资金池接近。
- 用户实际试用感受：功能和报表丰富，但分类较细、移动端交互繁重，缺乏希望的简单集中结算体验。
- 值得学习：预算拨款、类别结余/负余额、家庭协作场景。
- 不拟照搬：逐笔维护、多层分类、家庭监控功能。

## Actual Budget
- 开源且采用预算中心的模型，值得体验计算与数据处理方式。
- 重点验证：负余额结转规则、账单批量分类与账户预算关系。
- 链接：https://actualbudget.org/ 和 https://github.com/actualbudget/actual

## YNAB
- 值得学习：信用卡还款与预算支出的区分、零基预算法。
- 不直接采用其完整业务复杂度。
- 链接：https://www.ynab.com/

## 产品差异假设
以工资周期为主线，使用多卡账单聚合分配，而不是持续逐笔记账；资金池正负余额跨月滚存；尽量少的界面操作。
尚不能仅凭个人喜好判断存在广泛市场需求，本项目首先服务开发者自己。

## 后续验证
记录任务完成步骤、所需时间、用户困惑、账目可解释性；尤其考察一月后是否还能回忆出信用卡消费分类。
