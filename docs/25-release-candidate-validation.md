# 首版候选范围与综合验收

日期：2026-10-18。功能基线 v0.9.0。本轮确认功能已实现；正式 v1.0 标签仍待实际使用反馈及真机人工验证，不将自动化引擎测试写成真机认证。

## 连续三个周期

`src/domain/lifecycle.test.ts` 使用非敏感验收数据，完整执行：

1. 从严格校验的 v1 周期/资金池账本开始；录入收入后验证 v2 迁移仍无损。
2. 首周期部分还款后拆分结算，再记录尾款；数码资金池透支，预算仅扣一次。
3. 下周期固定拨款抵扣负结转，账单跨期拆分、显式调拨、更正、撤销、修改总额并重新结算及还款。
4. 第三周期继续结转；修正历史收入时先撤销关联拨款，再用新标识登记，后续余额精确重算。
5. 撤销并重记首期还款，不改变任何预算流水；每个关键阶段导出并恢复快照。
6. 各周期验证「期初 + 净拨款 - 净结算 + 净调拨 = 期末」，每笔调拨总额为零。独立手工拨款继续可用，不伪装成收入。

## 验证边界

自动检查覆盖类型、lint、领域/存储/界面、生产构建、三浏览器、深浅主题、窄屏与无障碍规则。Playwright 的移动视口及 WebKit 不是实际手机 Safari 验证；下一次人工体验建议走一笔真实操作前先使用无敏感数据完成建账、收入分配、跨期结算、分次还款及导出恢复。

仍采用浏览器本地数据；清理站点数据、设备丢失或未留备份可能导致丢失。系统无银行核对、现金资产核对或跨设备同步能力；已登记还款不证明银行已到账。
